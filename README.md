# PUBLIC TRACE

府省庁から部局・法人・基金・事業へ進み、予算、支出先、成果と出典をたどる静的サイト。

公開：https://nobby11334.github.io/govbizlist/

## 使い方

トップで年版と府省庁を選び、担当部局または関連法人・基金へ進みます。事業ページの「どんな事業？」「予算・財源」「誰に支出？」「成果・評価」「法人・基金」「出典・不足」で同じ事業の資料を確認できます。団体名・法人番号から関与事業への逆引きにも対応。

従来の資料別検索、7件の金額付き解説事例、全国1,741自治体の財政サイトへの参照は `advanced.html` に保持。従来の `#trace=` と `#municipality=` はそちらへ接続します。

## 収録範囲と根拠

| 資料 | 収録範囲・取得方法 |
| --- | --- |
| 2024年版レビューシート | 初回の原CSV15ファイル・553,094行を保存。2026-11-09に公式の訂正版3ファイルを接続し、現在の表示対象は552,353行。公開保存版 `team-mirai-volunteer/gov-vis` の固定コミット `5a7e4ab09149684caf7ab2f94fd977538edd4e04` から取得。5,664の事業IDへ集約 |
| 2025年版レビューシート | 公式ダウンロード画面から2026-11-06 JSTに原ZIP15ファイル・594,002行を直接取得。配布ページのデータ基準日は2026-01-19。全行・全列を5,794の事業IDに接続し、原ZIPとSHA256を保存 |
| 2025年版の読みやすい表示 | 概要・予算履歴・成果・点検・契約・支出ブロックの加工済み保存版を併用。元の取得記録を保持 |
| 2026年版 | 加工済みの暫定API保存データ5,825事業。概要、支出先、前年度執行額等。成果・評価の原データは未収録 |
| 基金 | 2024〜2026年版・354の継承ID系統。残高・交付・収支・返納・保有団体・支出先。実際の独立した基金数の確定値ではない |
| 独立行政法人 | 2024〜2026年版・814セグメント記録。複数年度・複数事業区分を含むため法人数ではない |
| 予算科目の対応 | 2025・2026年度のMOF/RS科目対応。計上額・翌年度要求額・科目全体の予算・推定・按分を区別 |

加工済み保存版の固定取得元は `team-mirai-volunteer/rs-vis` の `92721f7e50ebdd7fa38c29ab36ceb0c4487e182e`。ファイルの全件を保持しているが、加工時の文章の短縮等があり元CSV/APIの全項目とは限らない。2025年版は直接取得した原CSVを併記し、全項目を確認できるようにした。

2026-11-06 JSTの公式一括CSVページでは2024・2025年版の配布を確認。2026年版の全成果・評価を取得済みとは扱わない。通常のHTTP取得でHTMLが返る制約があったが、今回はブラウザーの公式ZIPボタンから2025年版を取得できた。

## データの解釈

- 年版は公開資料の年度。予算・執行・成果の対象年度は原列で確認し、別年度の値で空欄を埋めない。
- 予算・要求額・執行額・契約額・基金残高・返納を混ぜず、下流を含む支出先の金額を合算しない。
- 作成年の当年度執行額は未確定の場合がある。整形した履歴では未確定をnullとし、原CSVの入力値（0等）も保持して確認できるようにする。
- 2024年版の数値は原記載を保持し、単位の再照合が済んだものとして円換算しない。加工済み保存版の円単位の値と区別する。
- 「未収録」「保存版に値なし」「公式の非公表」を混同しない。未取得は不実施やゼロを意味しない。
- 内部組織の表記は各年版の担当部局、府省庁の親子対応は取得済みの所管情報を手がかりにする。2026年版は以前の組織情報を参照する部分があり、現在の法的な組織機構を全件再確認したものではない。
- 団体は法人番号の形式とチェック数字を確認し、確認できないものは同じ表記の候補を集約。番号の真正性や法人同一性の実証ではない。その他等の集約行は原事業の記録に保持。
- 自治体への参照は名称・自治体コードによる。国費と自治体の個別決算が会計上突合済みという意味ではない。
- 府省庁の活動実績・自己評価・目標達成率と、政策の因果的な効果の証明を区別する。

## 構成・再生成

- `index.html` / `catalogue.js` / `catalogue.css`：執行機関からの入口と統合詳細。
- `data/catalogue/`：年版別検索索引、40事業単位の圧縮詳細、組織・基金・団体関係と収録率。
- `data/official/`：公式画面から直接取得した原ZIPと取得記録。
- `data/rs/`：2024年版の原CSVを分割したJSONと取得記録。
- `data/extended/` / `data/evidence/`：加工済み保存版・追加予算科目資料の保存ファイルと取得記録。
- `scripts/build_catalogue.py`：同じ年版と事業IDで全原行を集約。
- `scripts/check_catalogue.py`：全事業参照・府省庁参照・団体参照・原CSVの行数・年版別件数を検証。
- `scripts/hydrate_evidence.py`：追加予算科目対応と2026年版契約方式を固定保存版から取得。

Python標準ライブラリで再生成可能。表示にはHTTP配信とgzip解凍に対応したブラウザーが必要。単純なfile://表示は不可。GitHub Pagesはmainブランチのルートを配信する。

## 更新

既存の取得ワークフロー成功後に `catalogue.yml` が再集約・検証・公開する。手動でも実行可能。変更時は最新mainを確認して他の編集を保持する。

毎週月曜の朝（日本時間）の保守更新を設定済み。公式の追加・訂正・新年度を確認し、変更を検証してから取り込む。同じ固定保存版の再取得だけを新しい公表データとは扱わない。原資料の取得日時・基準日と、再生成日時を分ける。

公式最新版との全数照合は未了。全国の全支払・再委託先・最終受益者を網羅したサイトではない。

## 2026-11-09 の公式API一覧照合

2025・2026年版のRS（レビュー）、KS（基金）、SS（独法セグメント）の一覧全ページを直接取得。`data/live/manifest.json` に確認日時、原API URL、ページごとのSHA256、圧縮保存ファイルのSHA256、重複・欠損検査結果を保存。日付別ディレクトリを保持し、既存CSV・加工済み保存版は上書きしない。

一覧件数は2025年版RS 5,798、KS 340、SS 272、2026年版RS 5,828、KS 328、SS 269。KS/SSはシート記録数であり、基金・法人数ではない。2025年版CSV 5,794事業に対する追加4件、2026年版保存データ5,825事業に対する追加3件を検索索引へ接続。2026年版は概要・担当組織を最新一覧で確認し、既存の契約・支出先・執行額は従来保存版として区別。追加3件の詳細API原応答も保存する。2025年版の既存CSV原記録は引き続き優先する。

これは一覧の直接取得であり、全シート詳細・全成果・評価・支出経路・自治体決算の全数突合ではない。API一覧の金額は原値として保存し、単位の未照合値を円換算・合算しない。`check_live_inventory.py` は全一覧と追加詳細が取得・検査できた場合だけ新しい一覧マニフェストを保存する。既存の固定保存版を再取得しただけでは更新しない。

同日、公式配布URLの2024・2025年版ZIP全30本を直接取得してSHA256を照合。2025年版15本は保存済み原ZIPと一致。2024年版は3-1（成果指標）118,019→118,071行、3-2（目標のつながり）28,362行で列名差異、5-1（支出情報）194,133→193,340行。`data/official-checks/` に照合履歴と差分原ZIPを保持し、現在の2024年版の検索・団体参照・詳細は訂正版に再接続。2024年版は合計553,094→552,353行。行数減少は削除失敗ではなく、直接取得した訂正版の内容差異である。従来の `data/rs/` は初回資料の履歴として保持する。
