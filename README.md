# PUBLIC TRACE — 国のお金をたどる

政府の予算・調達・執行・成果・財源、執行機関、自治体との関係を一次資料から確認する静的サイトです。

## 収録範囲（2026-11-05確認）

| 項目 | 収録範囲 |
| --- | --- |
| 国の決算 | 2024年度一般会計の決算概要・歳入内訳 |
| 事業 | デジタル庁の2026年公表一覧から8事業 |
| 執行機関 | 16組織・9つの執行体制例 |
| 自治体検索 | 全国1,741市区町村（2024年度の一覧） |
| 国の事業との接続 | 脱炭素先行地域・第1回選定26計画、45市町村と共同提案者 |
| 自治体の事業実績 | 横浜市・重点対策加速化事業の原資料への接続 |

自治体の5桁コードを共用し、[自治体財政サイト](https://nobby11334.github.io/local-budget-trace/)の個別自治体へ直接移動できます。既存財政データとの個別取引の突合や連結集計ではありません。

## 使用方法

`index.html` を開くだけで動作します。外部ライブラリ・ビルド・APIキーは不要です。`municipalities.json` は自治体一覧と関係データの参照用です。同じデータをHTMLにも同梱しており、ローカル表示でも動作します。

検索、組織種別・都道府県の絞り込み、事業詳細、事業保存（ブラウザー内）、CSV出力に対応しています。自治体は `#municipality=14100` の形式で直接指定できます。

## GitHub Pagesの配信設定

[Settings → Pages](https://github.com/nobby11334/govbizlist/settings/pages) で、Sourceを **Deploy from a branch**、Branchを **main**、Folderを **/ (root)** にして **Save** を押します。

このリポジトリへのファイル反映は完了しています。Pagesの配信有効化は別途必要です。

## データの解釈

- 所管関係と事業上の委託・補助関係を区別します。自治体や民間団体を府省庁の下部組織として扱いません。
- 選定・採択、交付決定、契約額、支出済額を区別します。金額未取得は0円を意味しません。
- 共同提案者を契約先・再委託先・補助金受取人と断定しません。
- 2022年の選定結果は当時の記録です。現在の選定状況や共同提案体制を網羅しません。
- 事業との関係が未収録でも、国庫支出金や国の事業が存在しないことを意味しません。
- 設備導入数・採択件数などの活動実績と、因果的な政策効果・費用対効果を区別します。
- 国と自治体の額を単純合算しません。一般会計の財源構成比を個別事業に按分しません。
- 一部資料のみを収録した試作版です。自動更新、全政府・全自治体の契約追跡、個別支払・成果指標の突合は未対応です。

出典はサイトの各項目とJSONに掲載しています。政府の公式サイトではありません。
