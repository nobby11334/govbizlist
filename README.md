# PUBLIC TRACE — 国のお金をたどる

政府の予算・調達・執行・成果・財源、執行機関、自治体との関係を一次資料から確認する静的サイトです。

## 使用方法

`index.html` と `trace.css`、`trace-data.js`、`trace.js` を同じディレクトリに置いて開くと動作します。外部ライブラリ・ビルド・APIキーは不要です。`municipalities.json` は自治体一覧と関係データの参照用です。同じデータをHTMLにも同梱しており、ローカル表示でも動作します。

検索、組織種別・都道府県の絞り込み、事業詳細、事業保存（ブラウザー内）、CSV出力に対応しています。自治体は `#municipality=14100` の形式で直接指定できます。

## データの解釈

- 所管関係と事業上の委託・補助関係を区別します。自治体や民間団体を府省庁の下部組織として扱いません。
- 選定・採択、交付決定、契約額、支出済額を区別します。金額未取得は0円を意味しません。
- 共同提案者を契約先・再委託先・補助金受取人と断定しません。
- 2022年の選定結果は当時の記録です。現在の選定状況や共同提案体制を網羅しません。
- 事業との関係が未収録でも、国庫支出金や国の事業が存在しないことを意味しません。
- 設備導入数・採択件数などの活動実績と、因果的な政策効果・費用対効果を区別します。
- 国と自治体の額を単純合算しません。一般会計の財源構成比を個別事業に按分しません。
- 一部資料のみを収録した試作版です。自動更新、全政府・全自治体の契約追跡、個別支払・成果指標の突合は未対応です。

出典はサイトの各項目とJSONに掲載しています。政府の公式サイトではありません。

## 金額付き追跡データ

`trace-data.json` に正規化した円単位の金額、金額区分、対象範囲、対象期間、出典、確認方法、未接続部分を保存。`trace-data.js` は同じデータのローカル表示用です。

収録事例：グリーンイノベーション基金、次世代型太陽電池の開発、横浜市エネルギーマネジメント・重点対策加速化、経営安定関連保証等特別基金、札幌市重点対策加速化、国のガバメントクラウド支援業務契約、千葉市ガバメントクラウド構築・運用保守契約。

四半期の基金数値16件は公表PDFの検索索引で確認し、原表の再照合待ちとして表示しています。他の金額15件は本文で確認。単位は元資料の千円・百万円・万円等から円に変換しています。通年の支出や特定企業への支出と取り違えないよう、四半期・期末・全体・内数・複数年度の区別を保持します。

契約額が分かっても支払額が分からないケース、国費と自治体の事業決算の対応が未接続のケース、効果が未測定のケースを明示します。端から端まで全ての金額がつながったことを意味しません。特別会計の体系的な収録は未対応です。
